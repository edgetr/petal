Support

Run Petal's built-in check first when something looks wrong, see what stays on your Mac, or report a bug or security issue.

Troubleshooting

Open Settings › About › “Check Petal” to check Petal's signature, damaged settings files, unknown settings, apps no longer installed, macOS's Dock hidden while Petal isn't running, the Dock helper, whether your AI is installed and signed in, and Petal's skill. Choose “Fix these” to repair what it safely can — damaged settings files are backed up before starting fresh.

You can also open the AI panel and choose “Something in Petal isn't working right”.

  • Petal AI does nothing: test claude -p hi (or codex) in Terminal to confirm the AI tool works on its own, then check Settings › Petal AI.
  • macOS's Dock didn't come back after a crash: wait up to 30 seconds for Petal's Dock helper, or run petal restore-dock in Terminal.

In Terminal. Run petal doctor for the same check, or petal doctor --fix to repair what it safely can. Run petal logs (optionally followed by a number of minutes; default 30) to read Petal's own log — it never records titles, addresses, file names or what you wrote. Run petal restore-dock to bring macOS's Dock back as you had it.

Reporting a problem

Choose Settings › About › “Report a problem…” (or run petal report "<what>" in Terminal). Petal leaves out your name, window titles and files, lets you review everything with “Show the report”, and posts to Petal's public GitHub page once you choose “Post it”. Posting needs a GitHub account.

Privacy in brief

Petal has no server and no analytics. What you ask Petal AI goes through your own Claude Code, Codex or API key. Website shortcut icons are fetched from the sites themselves, and update checks go to GitHub.

Your data stays on your Mac (and iCloud Drive for notes):

  • Vault items in your Mac's Keychain.
  • Settings in ~/.config/petal/.
  • Notes in iCloud Drive's “Petal Notes” folder.
  • Chats and history in ~/Library/Application Support/Petal/.

Security issues

Report security problems privately at GitHub Security Advisories — never in a public issue. Include your Petal version (from Settings › About), your macOS version and steps to reproduce. Only the newest release receives fixes.

Contributing

Petal is open source under the MIT license at github.com/edgetr/petal. Search existing issues before opening a bug or idea. New features need an issue the maker agreed to first; keep each pull request to one problem and show that it works. See CONTRIBUTING.md in the repository for the rest.

Building from source. Requires macOS 26 or later and Swift 6.2 or later command line tools, with no external dependencies:

git clone https://github.com/edgetr/petal
cd petal
macos/build.sh
macos/checks/run.sh
