The vault

The vault stores logins, contact info, addresses, payment details and API keys in your Mac's Keychain so Petal can fill forms without Petal AI ever seeing a secret.

What goes in the vault

Add items in Settings › Vault › “New item”. Five kinds are supported:

  • “Login”, with “Websites” and “Apps”.
  • “Contact info”, with a “This is me” option.
  • “Address”, which can belong to a contact.
  • “Payment info”.
  • “API key”.

Older items without a kind appear as “Unsorted” under “Tell Petal what each one is”; until you classify them, Petal asks before filling them.

Every item is stored individually in your Mac's Keychain, never in a plain file. Viewing a saved secret or exporting requires Touch ID or your Mac password.

How Petal AI fills forms

Petal AI sees item kinds, titles, sites, usernames, contact info, addresses, and a card's name, last four digits and expiry. It never sees a password, card number, security code or API key — Petal types those values itself.

  • A login fills on its own only on its matching website or app. Anywhere else, a card asks first and defaults to “Don't”.
  • When a form needs something not yet saved, Petal shows a card for you to type it in, with “Save to your vault”.
  • For a new account, Petal can also generate a strong password, save it and fill it in.

Two-factor codes aren't supported yet, and Petal AI never asks for a password in chat.

Buying

Purchases always stop for your approval with a card: “Buy on <site>?” showing “Petal AI says: “<item, price>”. Pays with <card>.” and buttons “Buy” and “Don't”. There is no “Always” option, and purchases only run over https.

Import and export

Open Settings › Vault › “Import” to bring in items “From Apple Passwords, Chrome, Proton Pass or Petal” by choosing or dropping a file. Afterward, Petal offers to move that file to the Trash.

Choose “Export” to save “Everything, as a Petal file” or “Logins, for Apple Passwords or Chrome”.

Careful. An export holds your secrets as plain text. Remove the file once you have imported it where you need it.

Sharing keys with coding agents

You can let Claude Code, Codex and Terminal commands use API keys from your vault without seeing them. See Your own agents.
