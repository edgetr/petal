Helpers in notes

Any Petal Note can run background tasks when you type @Petal, and understands plain-word instructions for reminders, page watchers and daily notes.

Typing @

Type @ in a note to open a menu with “Petal” followed by your notes and notebooks by name. Chips show what each @ and understood date or time bound to (such as “Friday 9:00”). When you want a specific model, name it in plain words — there is no @Claude or @Codex.

A line runs only when you press Return at the end of it, in that note, and only if you typed or pasted it. Synced, imported or tool-written text never runs on its own. After a restart, an older line runs again only once you edit it. A bare @Petal isn't sent (“Ask Petal something after @Petal”).

How @Petal works

@Petal runs your chat AI with Petal's tools on the note's place in the background (up to 4 runs at once). The answer appears as ink on the front of the note, and the next run replaces it. Flip to the back to see its steps and a stamp for each permission you allowed (“Tap a stamp to take it back”).

While it works, you can choose “Show me”, “Pause” / “Go on” or “Stop”. If a run doesn't finish, you get “Try again” (only on the Mac that sent it) and “Edit”. When a step needs approval, a card appears on the note with “Allow” / “Don't”, or “Buy” for a purchase.

Plain-word instructions

Plain instructions trigger built-in behaviors; questions or conditions go to the helper as normal requests instead.

  • Bring a note back: “bring this back Friday” or “remind me …” with a day, a time, “the 20th” or “next month”. Without a time, Petal asks “When?”.
  • Notebook memory: “remember …” or “forget …” adds or removes lines on the notebook's cover under “Petal remembers”.
  • Pack up a workspace: “put this away” saves the window's tabs, file and mail into the note with an “Open all” button.
  • Watch a page: “check this every morning, tell me under $300” (include a repeating phrase such as “every”, “each morning”, “keep checking” or “tell me when”; defaults to daily at 9:00). Petal fetches plainly and asks the AI only when it can't read the value. It never buys. Write “stop watching” to end it.
  • Chain or compare notes: “when @Research is done, draft @Proposal”, or “check this against @Notebook”.
  • Morning notes: “leave me a note every morning” (8:00 by default). Write “stop the mornings” to end it.

This Mac only. Chains, watchers and morning notes run only on the Mac where you wrote them.

Notes on code

For engineers. A note stuck to a GitHub pull request or issue, or to a file inside a git repository in your home folder, runs your Claude Code or Codex in the note's own git worktree of that checkout — only when the line asks for work, after asking once per project. On a pull request from a fork, the project's own settings, hooks, tool servers and instructions aren't loaded. The PR link and proof come back as ink. You can name another model for a second opinion, such as “have GPT 6.1 Sol look for holes”.

Privacy and redaction

A “Private” notebook can be read only by a note inside it. Everything a helper writes back passes through the vault's redaction before it is shown or saved.
