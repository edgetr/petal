Make it yours

You can shape Petal by asking Petal AI in plain words, through the Settings window, by editing its files, or by changing Petal's own code.

Ask Petal AI or search Settings

Ask Petal AI for what you want — “stop the icons bouncing”, “turn off the app glow”, “bigger icons” or “dock on the left”. You can also open “Petal Settings…” from the menu-bar mark or by right-clicking the dock, then type into “Ask Petal AI, or search settings” at the top of the window. See Settings for a page-by-page tour.

For instructions you want Petal AI to keep in mind every time, write them in Settings › Petal AI › “What Petal AI should always know”.

Changing Petal's own code

When no setting does what you want, you can ask Petal AI to change Petal's own code. Petal builds a copy signed for this Mac and restarts into it. This requires Apple's command line tools.

When a new Petal release arrives, Petal carries your changes onto the new version, handing any conflicts to your Claude Code or Codex. If that fails, your current Petal keeps running, nothing is lost and an alert says “Petal <version> couldn't take your changes” with “OK” and “Report…”.

In Terminal. Manage personal code changes yourself with petal personal init, make your edits, then run petal personal save "<what changed>". Other subcommands are status, list, undo, reset, retry and restore.

Config files

For engineers. Petal keeps its config in ~/.config/petal/ and reloads files within a second when you save them:

  • settings.json holds every setting.
  • dock.json holds the dock's apps in order, position, auto-hide and related layout.
  • instructions.md holds the same text as “What Petal AI should always know”.

Hand edits that would give Petal AI more power — widening its access, letting it use your apps or removing apps from “Kept private” — are refused and put back. Those change only in Petal's own settings.

The petal command

For engineers. While Settings › Petal AI › “Let other AI agents change Petal” is on, Petal links the petal command at ~/.local/bin/petal. See Your own agents for petal run and vault keys.

petal apps                the dock's apps, in the order they show
petal get                 everything about the dock: settings (with help), its apps, files
petal set <key> <value>   change a setting (value as JSON: true, 44, "#d9367f", ["~/Downloads"])
petal dock [petal|macos]  which dock is showing, or switch
petal ask | chat <text>   open the AI panel, or open it with <text> typed for you to send
petal chats               your kept chats with Petal AI, to read again or carry on
petal search | settings   open the "+" search, or Petal's settings (settings privacy: a page by name)
petal restart | update    restart Petal, or check for a new one
petal doctor [--fix]      check Petal, and repair what it safely can
petal report "<what>"     tell Petal's maker what went wrong (a GitHub issue; shown to you first)
petal restore-dock        give macOS its Dock back, even if Petal crashed
petal logs [<minutes>]    Petal's own log, the last 30 minutes (or as many as asked)
petal personal …          your own changes to Petal's code, kept through updates (petal personal help)
petal run --key "<title>" [--env NAME] [--stdin] -- <command…>
