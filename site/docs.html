Docs

Petal is a free, open source dock for the Mac (macOS 26 or later), with sticky notes, a vault, routines and Petal AI built in. Petal AI uses your own Claude Code or Codex plan, or your own API key, and everything else works without an AI at all.

Getting startedInstall Petal, set up an AI or skip it, allow permissions and update.

Your dock

The dockApps, website shortcuts, stacks, previews, now playing and window tiling.Make it yoursAsk Petal AI, edit settings files, use the petal command or change Petal's code.SettingsA page-by-page tour of every group in the Petal Settings window.

Notes

Petal NotesSticky notes on anything, notebooks in iCloud Drive and Petal's viewer.Helpers in notesRun @Petal in a note, set reminders, watch pages and work on code.

Petal AI

Petal AIQuick questions, approvals, using your apps, hidden screens and memory.RoutinesAsk once to sort files, hide apps or run Shortcuts automatically.

The vault

The vaultLogins, cards and API keys in Keychain that Petal fills without showing AI.Your own agentsConnect Claude Code or Codex to Petal, and share vault keys safely.
