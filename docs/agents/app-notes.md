# Petal.app: Petal Notes

- **Petal Notes** (`notes`; phases 1 to 5). Its internals, rule by rule, are in `docs/petal-notes.md`: read the part you're about to change first. What every agent must always hold to:
  - **Every change to a note's file goes through its session** (`NoteSession`, by the note's own id): the journal first, a based write that lands only on the exact text it was made on (else a conflict copy beside it), the identity check inside the coordinated step (`NoteShelf.stillNote`), nothing lasting kept before a note has a real id. Never write, move or trash a note file any other way; nothing is deleted, only moved to the Trash (`NoteStore.toTrash`).
  - **The main thread never waits** on the disk, iCloud, Accessibility, AppleScript, the window server, the Keychain or the network. Files are read and written on `NoteStore.io`; the folder is read one read at a time (`NoteStore.reload`), and a file that didn't change isn't read again (`ReadCache`).
  - **Layout is the only path that reveals a panel** (`NoteDesk.layout`, `placementNow`): a paper shows in one place only, a read becomes the active scene only through the one gate, and hiding is by going clear, never ordering out. A headless run (a check, a bench) never orders a window of Petal's in.
  - **Tools see handles and redacted text**, never a path, a file name or an id taken from one: every answer goes through `NoteShield` (the vault's redaction before any cut or derivation, nothing told while the vault can't be read) and then the Private fence (`NotePrivacy`, checked again right before it's handed over).
  - **One readiness sequence** (`NoteStore.switchRoot`, at launch and at every switch of `notesFolder`): the old folder drained, this Mac's journal put back, the first read, what was pending replayed, and only then `notesReady`. Every way in from outside goes through `NoteDesk.takesChanges`.
  - **One way to quit** (`PetalApp.quit`, from the run loop): `NoteDesk.prepareToQuit` waits for the journal, then drains every session.
  - **One binding** for everything pending against a notebook (`NotebookBinding`, `NoteShelf.notebookFor`) and one `RootSession` for everything kept for the notes' folder in use: never resolved against another folder, never guessed between two candidates.
  - **One loader lifecycle** in Petal's viewer (`ViewerLoads`, `ViewerLoadUnit`): one load at a time, one follow-up, the path rule and the file's identity checked at every read; passages are found by their words; versions are made on copies and the viewer never changes the original.
  - **Shielded helper output, one way in and one way out**: every paid call starts through `NoteHelpers.start` (the vault readable, the admission gate, then a prompt made only of `Shielded` parts), every run is one `RunToken` and ends once through `NoteHelpers.end`, and everything a helper produces is shielded whole as it arrives. Every line of What Petal AI did goes through `Assist.did` as a `HistoryLine`.
  - **When in doubt, keep the person's data**: copy rather than move, refuse rather than guess; a wrong note is worse than a missing one.
  - **The files:** `NoteFile.swift` (the file format, places, matching, edge tabs, room: pure), `PaperNotes.swift` (`NoteStore`, sessions, reads, covers, canvas writes), `NoteJournal.swift` (this Mac's journal and recovery), `NoteDesk.swift` (the notes on the screen: reading what's in front, layout, room, Desktops), `NoteViews.swift` and `NoteEditor.swift` (the paper, the editor, pictures), `NoteTools.swift` and `NoteShield.swift` (the note tools and what they may tell), `NoteHelp.swift` (helpers' words, front matter, `RunToken`, `Shielded` prompts: pure), `NoteHelpers.swift` (runs, the gate, watchers, chains, the reading lens), `NoteMentions.swift` and `NoteHelpViews.swift` (chips, the @ menu, ink, the helper's bar), `NoteTasks.swift` (Open all), `NoteLibrary.swift` (the contract's fields, views, search, canvas, privacy: pure), `NotesWindow.swift` (the Petal Notes window, grid and canvas), `NoteDock.swift` (a notebook's stack, a note dropped on an app), `NotePad.swift` (the note pad in the dock, the paper dragged off it, and what picks a paper up on the screen: `PaperGrab`, with the open hand), `ViewerFile.swift` (pure), `Viewer.swift`, `ViewerViews.swift`, `ViewerTools.swift` (Petal's viewer), and for checking `HelpersCheck.swift`, `ViewerSnapshot.swift`, `ViewerSamples.swift`, `NotesBench.swift`.
